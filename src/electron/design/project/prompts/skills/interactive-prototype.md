name: interactive-prototype
title: Interactive prototype
description: A working app with real interactions
---
Build a fully interactive prototype with realistic state and transitions. Use React state and effects (`useState`, `useEffect`) for behavior. Include hover states, clicks, form validation, animated transitions and multi-step navigation. It should feel like a real working app, not a static mockup.

- Real data shapes: lists with plausible lengths, a long name, an empty state where one would happen, numbers and dates in the formats the product's users expect.
- Every control the user can see does something, or is visibly disabled. Navigation moves between real screens that share state.
- Keep the app in one entry HTML plus a few .jsx files (data, shared components, one file per screen group, the app last).
- Put options and variants behind tweaks in the same page instead of forking files.
- Center the prototype or let it fill the viewport; no title screen.
